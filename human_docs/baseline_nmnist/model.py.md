# 文件：`baseline_nmnist/model.py`

## 作用
- 定义一个 DECOLLE-like 的 N-MNIST SNN 模型。
- 用 3 个 `7x7` 卷积层和逐层 LIF 神经元构成紧凑的时序分类网络。

## 架构要点
- 输入通道为 2，对应事件正负极性
- Conv 通道数为 `64 -> 128 -> 128`
- 每层后接 BatchNorm 和 LIF
- 使用平均池化降低空间尺寸
- 最后接线性分类器输出 10 类

## 说明
- 这是一个 **DECOLLE-like** 对标模型，而不是完整实现 DECOLLE 局部分类器训练算法。
- 当前目的是在 N-MNIST 上建立一条与现有量化链兼容、结构上接近相关工作的实验主线。
